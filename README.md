# WhatsApp Web Clone with Enhanced Messaging Features

This workspace contains a local-first WhatsApp-style clone with:

- React + TypeScript frontend
- Express + Socket.IO backend
- In-memory storage for users, chats, messages, stories, highlights, scheduled messages, and notifications
- Local authentication flow, chat UI, stories, highlights, and scheduled messages

## Run locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Open the frontend at http://localhost:3000 and the backend at http://localhost:5000.
